2.0 / 开仓前的固定顺序

天时→地利→题材→阶段→个股→地位→模式→仓位（强天时还是弱天时）→买点（择日和分时）→卖点（择日和分时）

先判断天时与地利，选择题材并标注阶段，再筛选个股、确认地位、匹配熟悉模式。仓位先区分强天时还是弱天时，再定风险预算；买点和卖点都要分别写清择日与分时，不从单票唯一性直接跳到开仓。

  1. 01 / 天时市场能不能做

    赚钱效应最重要，情绪周期次重要；同时检查亏钱效应、监管压力、连板高度与市场主导风格。

  2. 02 / 地利辨清题材竞争与市场阵眼

    比较题材强度、预期、持续性与节奏，观察更强方向是否卡位，并锚定市场情绪核心。

  3. 03 / 题材选择最有预期的方向

    在地利判断中筛选题材，结合催化、容量、梯队与核心反馈，不因单票强就跳过题材筛选。

  4. 04 / 阶段定位后再谈参与

    分别标注新题材、旧题材、总龙与补涨所处阶段。阶段是前置条件，不是买后解释。

  5. 05 / 个股从题材中筛选候选个股

    比较量能节奏、承接与题材或市场共振，选择值得继续核验的个股；个股强不等于核心地位已经成立。

  6. 06 / 地位确认身位、核心身份与唯一性

    核对龙头七维、题材内与跨题材唯一性、市场核心地位和卡位结果。同身位竞争未结束，不自封龙头。

  7. 07 / 模式匹配熟悉战法

    结合天时、题材阶段与确认后的个股地位选择普通龙头、补涨、切换或二波。有符合条件的补涨优先做补涨。

  8. 08 / 仓位先区分强天时还是弱天时

    按强弱天时选择仓位与退出预算，先写总仓、单票预算和最大亏损，再决定数量。预算是有条件的上限，不是每天买满的任务。

  9. 09 / 买点择日与分时分别确认

    择日：弱转强日还是转强确认日？分时：半路、上板扫板还是回封？按模式规定执行，没有熟悉模式内买点就等待。

  10. 10 / 卖点择日与分时提前写清

    择日：哪一天、哪个阶段兑现或因失效退出？分时：哪个触发节点减仓或清仓？弱天时优先兑现，强天时仅在逻辑有效时延长持有。

01 · 阶段是前置条件，不是买后解释
每日分别标注新题材、旧题材、总龙与补涨所处阶段。有补涨优先补涨；切换例外要有更强题材效应、合适节点与较低试错仓位。
02 · 唯一性必须在正确天时里才有意义
非主导科技的单票唯一性不能代替市场主线；同身位竞争未结束不能自封龙头。闽东选对，仍要尊重当时的高度压力。
03 · 买点分三类，窗口错过不互相借用
普通龙头分时板上确认、补涨三板、二波严格尾盘窗口分别执行。百花、时代、欢瑞三种失误不能笼统归为“买早”。
04 · 仓位不能用来修复错误
百花与西陇摊低成本是已确认的错误动机；爱仕达弱切换重仓是风险错配。先确定最大可承受损失，再决定数量。

02 / 交易世界观

天时、地利、人和，与交易纪律

先判断市场能不能做，再选题材、选个股，最后用买卖点、仓位管理、失效条件和赔率约束交易。

重点总纲 先天时、再地利、再人和、最后交易。

天时不好快进快出，天时好快进慢出。

仓位与持有耐心都跟随市场，而不是跟随主观贪婪或恐惧。

快进以买点确认为前提，慢出以逻辑持续为前提；没有匹配机会就空仓，条件失效仍按纪律退出。

决策总纲 / 四层分工

能不能做 → 做哪个题材 → 做哪个个股 → 怎么交易

01 / 天时能不能做、最匹配哪种模式
看监管压力、连板高度限制、赚钱效应（最重要）、亏钱效应、情绪周期（次重要）、市场主导风格与短线炒作情绪，决定参与资格、战法模式与总仓预算。
02 / 地利选择最有预期的题材
比较题材强度、题材预期、持续性与节奏、题材阶段，并锚定市场情绪核心标的；不能因为单票强，就跳过题材筛选。
03 / 人和选择最核心的个股
核对龙头（或核心）量能节奏是否与题材或市场共振，再用龙头七维与唯一性检查卡位关系；个股条件再好，也不能覆盖天时给出的约束。
04 / 交易哪一天、哪个分时节点进出
沿“天时 → 地利 → 题材 → 阶段 → 个股 → 地位 → 模式 → 仓位（强天时还是弱天时）→ 买点（择日和分时）→ 卖点（择日和分时）”执行。先确认个股地位，按强弱天时前置仓位预算；买卖都分别选择日期、阶段和分时触发节点。
天时

能不能做、用多少仓

先定风险预算，再谈题材与标的。

01 监管压力与连板高度限制

看监管压力、连板高度限制、空间高度、前高突破与指数状态。尊重实际晋级和高标负反馈，不能因单票选对就忽略高度压力。

02 赚钱效应最重要，兼看亏钱效应

先识别市场正在奖励哪种交易，再统计晋级、溢价、炸板和大面来源。涨停家数多但亏钱效应重，依然不能重仓。

03 情绪周期次重要，兼看短线炒作情绪

确认市场处于混沌、主升还是退潮，观察短线炒作情绪与风险偏好；情绪阶段不能替代实际赚钱效应。

04 市场主导风格

确认资金正在奖励连板接力、趋势抱团、容量核心、20cm、低价股还是ETF。中高位负反馈严重且没有溢价时，暂停该模式，只使用已经掌握的匹配方法。

01 题材强度与题材预期

比较题材强度、催化预期、性质、容量和梯队，选择最有预期的方向；题材预期须持续用市场反馈检验。

02 题材持续性、节奏与阶段

标注启动、续强、分化／分歧、回流或退潮阶段，检查持续性和节奏。最晚四板前看见强板块效应；结合涨停数量、梯队与环境相对排名，弱绝对强度下可参考当天前三，不能解除市场暂停条件。

03 市场情绪锚定核心：阵眼

寻找整个市场情绪锚定的核心标的，相当于“阵眼”。部分核心可阶段性脱离板块而独立；仍要区分市场核心与普通单票唯一性，不能据此豁免模式边界。

同时看板块最高标、容量核心与人气股的竞价溢价、承接和回封。辨识度个股持续正反馈，才说明资金认可方向；本系统战法6、8仍要求题材持续性，不参与板块效应结束后的总龙独自穿越。

先区分强天时还是弱天时，写最大可承受损失，再规划建仓、加仓与减仓。弱环境总仓70%–80%、单票30%–40%；强环境条件成立时总仓可到100%、单票60%–80%，均为有条件上限，仍取模式与风控约束中的更低值。仓位不能修复错误。

03 / 市场启停

短线投机的周期论

短线投机行情不是按月份平均出现，而是由一个能打高度、能走二波的总龙打开风偏后，才可能出现一段可做窗口；历史记录约1.5到2个月，不据此预设固定持续时间。

先找“开启行情的总龙”，再判断投机情绪是否已经打开；窗口没打开时，不要硬做月度均值，只做小仓试错和等待。

启用、观察、暂停与恢复的完整判据展开阅读

当前主攻的是三进四、四进五的连续晋级模式。先识别市场正在奖励什么，再决定是否启用；中高位负反馈严重、封板后普遍没有可兑现溢价时，暂停该模式。五月底、六月中曾被记录为负反馈较重的阶段，具体日期仍待逐日复核。趋势、反包或低位轮动有机会，不代表中高位连续接力仍然适用。

开启观察：高度龙出现、连续四个及以上的一字缩量板向上打开空间，是个人经验中的重要信号；还要看到换手梯队晋级、题材扩散与次日溢价。负责打开空间的一字高标可以作为情绪观察对象，并不因此成为自己的买点。

观察高标失去带动作用；三进四、四进五受阻；单次大分歧后修复质量未定。降低进攻意愿，检查当天是否恢复承接，以及次日参与者能否得到回报。
暂停候选群体反复缺乏次日溢价，同时出现跨题材、跨层级负反馈和修复失败。暂停中高位连板新介入；一只独立高标不足以恢复模式。
恢复观察换手梯队与实际溢价重新出现，失败者的承接改善。依据新证据重新评估，不仅凭又出现一只一字高标恢复进攻。

五项固定记录

  1. 成功者反馈：昨日封板者今天有没有可兑现溢价，不用次日最高价代替实际可实现的收益。
  2. 高度下方梯队：三进四、四进五是否连续受阻；最高板还在，也可能只有一字板、缺少可参与的换手接力。
  3. 修复有效性：老高标反包能否带动梯队，修复次日是否还有承接；修复交易再次亏损，比单次分歧提供更多警示。
  4. 失败者与扩散：昨日炸板、断板股是修复还是继续大跌；损失是否从单个竞争者扩展到不同题材、不同层级核心。
  5. 风格相对表现：指数、趋势或反包能修复，而连续晋级仍亏损，提示当前模式与主导风格不适配。

战法6与战法8的共同前提

强题材反复发酵时，高位总龙通过震荡和趋势上涨维持高度与辨识度，低位新核心通过连板提供新的赚钱效应。我的两套首选模式，分别参与总龙二波和总龙趋势下的补涨中位。

连板是一致性加速，一字连板体现更强的一致性。高度上升后，获利盘与畏高资金形成分歧，仍看好题材的资金可能通过趋势上涨继续参与；低位新核心则承接连板弹性。像大人和小孩各有不同的成长节奏，两类核心共同延续题材。

  • 题材够大
  • 情绪够强
  • 总龙趋势在
  • 无强题材卡位
  • 补涨周期轮动
  • 大盘不崩
  • 监管不极端

总龙趋势是共同前提：总龙退出，补涨也退出。总龙断板A杀、题材无二次发酵或情绪退潮时，不把三板身位直接当作补涨买点。板块效应结束后的总龙独自穿越，不参与。

我的经验分类是3天小题材、5天中题材、8天大题材、12天二波大题材、30天三波超大题材。“持续性强”至少要有看向12个交易日的预期。事前根据启动消息、叙事空间和催化预期判断，带有感性成分；事中再通过走势确认。

预期节奏为强启动 → 续强 → 分化／分歧 → 回流。龙头和题材连续两次分化分歧后依然回流，是我判断持续性与超预期的线索，只能事中识别。

先看情绪和大盘

观察涨跌停家数、市场总量能，以及上证指数、深证成指是否处在下降波段。监管环境的交易反馈，看高位连板与高辨识度标的是否出现极端负反馈。

旧题材仍强，有补涨先做补涨

主升阶段优先前排核心，再看分支核心、补涨与后排跟风。主线确认后倾向早进，重视3—5板唯一性身位；唯一性未出现前不大仓位押注。同身位优先换手放量、节奏稳定者。模式上首选总龙二波与补涨中位，再观察高切高和首板补涨。

旧题材总龙二波优先于仅连续两天强势的新题材。新题材至少连续两天强板块效应（涨停数超过15个、板块涨幅明显）只是切换候选；旧题材仍在时，要看第三天分化分歧与第四天回流。

新题材扛过第三天分歧、第四天强回流，而旧题材仅勉强维持，就切换到新题材。兼有旧、新题材标签的核心，暂按当时更强题材归属，保留判断上的困难。

温和退潮、高位震荡时观察补涨与切换；主线大分歧后不能再强回流，考虑切换。极端退潮不做补涨，等待退潮基本结束后再切换。

战法6 / 总龙二波

连板龙转趋势龙：龙头二波

第一波断板后保持高位强度，题材二次发酵、新补涨出现，与总龙突破前高形成共振。

题材确认
题材二次发酵，第二波出现补涨周期；短线情绪好，没有更强题材卡位。
价格确认
突破上一波最高价＋当日相对昨收涨幅达到5%，两项同时成立，不要求涨停。5%不以上一波最高价为基准。
量能确认
不低于整理期均量；总龙已有空间高度和人气辨识度。
实际执行
当天尾盘确认后买，不等次日再追。在最后三分钟检查突破与涨幅仍成立后执行；最终收盘结果仍可能变化。
联动与空间
还需检查补涨共振、题材反馈与监管空间；价格达标不能单独覆盖这些前提。
窗口纪律
窗口严格，买点基本唯一确定；错过不补买、不追。不把尾盘错过变成次日高开追仓。
仓位安排
一般约半仓（账户资金约50%）。先参与总龙二波，预留另一半仓位；补涨龙通常较晚出现，等其符合买点后再配置。

退出看首次深水与持续走弱：首次收盘跌幅达到或超过5%，至少减掉该持仓3/4；接近风险条件也可提前走。总龙连续两天走弱，直接卖出。

二波触发口径：尾盘确认价 > 上一波最高价，且（尾盘确认价 ÷ 昨日收盘价 − 1）× 100% ≥ 5%。这是同一天的联合条件；既不是比前高再涨5%，也不是次日补追的依据。

总龙在二波启动之前识别

以题材内空间高度最高、人气榜前列与已有辨识度确认总龙。后续表现与相对地位改变时，重新判断；最早启动只是线索之一。

第一波断板后没有连续负反馈，能够高位震荡，题材仍维持强度，才有等待二波的基础。高位震荡参考是从第一波最高点计算，收盘回撤不超过12%，盘中不单独按此标准判定。

连板转趋势的环境

题材体量与持续性足够、短线情绪好，且没有其他强题材卡位。连板高度受到压制，但断板没有连续负反馈时，重点观察最核心个股能否转趋势。总龙通过高位震荡等待后续发酵，后续补涨与其二波、三波可能共振。

高开与低开

已有持仓、仍有仓位余量时，明显高开只作为强度观察；加仓必须另有预先写明的模式内触发与风险预算。不能因前一天买少或错过尾盘，在次日高开补追。此前满仓则观望。低开跌幅超过4%，且不能迅速回到水上就卖。题材和补涨仍强时可等总龙反抽到水上，但连续两天走弱直接卖，不继续依赖反抽。水上以昨收为基准。

尾盘最后三分钟提前执行，也用于卖出。剩余仓位按金字塔原则逐步减少、退出；不赌反包，不把最后1/8美元的鱼尾利润作为必须完成的收益目标。

战法8 / 补涨中位

总龙趋势下补涨连板龙：补涨龙中位3板

有符合条件的补涨优先做补涨，三板是主要观察与参与节点。总龙趋势在、题材效应强、板块节奏稳，补涨核心在二进三上板时形成题材内最高连板唯一性。

共同前提
总龙继续趋势向上，题材有持续性与强度，补涨周期能够接力。
标准买点
二进三上板确认＋题材内最高连板唯一；唯一性未出现前不能大仓位参与。
竞争者失败
竞争者大跌淘汰后留下的唯一性，当天不买，次日转强确认才能买；观察涨停等转强表现。
窗口与补买
买点基本唯一确定，三板优先。错过后再出手一定要十分谨慎；3进4需更强唯一性与环境支持，不能把汉森盈利扩成普遍追高依据。
退出联动
总龙退出，补涨也退出。补涨仍封板，不能替代总龙趋势这个前提。
仓位安排
一般约半仓（账户资金约50%）。补涨龙通常晚于总龙二波出现，符合二进三唯一性等买点条件后，再配置预留的另一半仓位。

量能例外只放在题材二波以后：新补涨股自己的第一轮连板，也可豁免半放量、全放量等节奏；连续极致缩量一字、极致二连加速，不随意参与。

三板身位、量能例外与首板补涨区分题材大小和参与阶段
三板是辨识与参与节点

首板难以分辨后续核心，二板可能通过加速表态，三板重点看身位与唯一性，买点基本唯一确定。错过三板后，不自动借用普通龙头的四板、五板买点；3进4仅在更强唯一性与环境支持下谨慎评估。

补涨高度结合总龙空间判断，约总龙高度一半、部分只到三四板，是我的经验参考；常见约四板是经验范围，不是固定高度上限。若只预期到四板，就接受这一段收益；汉森的盈利或后续高度不能扩成普遍追高依据。

题材与龙头第一波发酵，量能标准不能随意放宽。同身位优先健康换手；四板及以下烂板爆量可能消化分歧，五板及以上高位爆量烂板更需谨慎。题材二波以后，部分量能节奏可放宽，但过度一致的连续极致缩量加速仍需回避。

大题材看补涨周期

大的补涨是各轮核心接力的补涨周期，各轮领涨核心与分支共同维持大周期强度。题材大小、整体情绪和持续性决定它能承载多少轮；也要锚定总龙能否高位震荡、走二波或三波。

小周期减少补涨、多观察切换。缺少完整二波总龙时，补涨可能只有2—4天，四板附近结束，二板又可能一字加速。不能因为到了三板就预设空间充足。

首板阶段接受随机性

首板补涨不重仓单押，若做则平铺3—5只首板或二板候选；这与唯一性确认后的核心参与分开。首板辨识困难，仍要结合题材大小、强度与持续性。

医药周期的首板观察，是在我关注的监管节点前一天尝试：关注周期内此前未涨停、小盘低价、强势直线拉升、最早涨停前两名的候选，例为澳洋健康。这一具体做法不选已有二板或几天几板的票。

两套战法的仓位与退出

个人仓位设想与风险承受

先过天时预算：以下各半仓、合计满仓的配置不能独立启用，仍受强弱环境仓位计划与盯盘条件约束。天时偏弱时不照搬满仓设想，取适用规则中更低的仓位上限。

两套战法各安排约半仓：通常先以约半仓参与总龙二波，补涨龙较晚出现，符合买点后再配置预留的另一半。两者都确认时，同题材合计仓位可到100%，覆盖趋势与连板两类核心机会。两部分仓位共同依赖同一题材，题材退潮时可能同时受损；总龙退出，补涨也退出。

一次失败约10%的账户损失，是我的风险承受预期，实际可能因无法成交而超过。超过时接受已经发生的损失，暂停该题材，等待切换。卖单未成交时继续尝试退出，发出委托后仍需确认实际成交。

确认顺序：旧龙修复 → 新龙承接 → 高低切共振
  • 旧龙修复：强烈负反馈消退，开始企稳；进一步转为正反馈时，新旧周期切换的共振更理想。

核心逻辑：旧周期止跌，新周期接力，资金完成高低切换。
